# faz155: KAP cache loader

## Motivation

Add `BIST_KAP_CACHE_DIR` as a first-class env var for pointing directly at a KAP HTML cache directory. This aligns with the backlog "Offline KAP cache ingestion" priority and the sprint doc: "BIST_KAP_CACHE_DIR or data/raw/kap_html".

- **Scope guard**: Offline only. No network. All reads from local paths.
- **Precedent**: KapHtmlEventsProvider already supports BIST_KAP_RAW_DIR, BIST_RAW_DIR. Add BIST_KAP_CACHE_DIR as the preferred alias for a direct cache path.
